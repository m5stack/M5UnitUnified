Detailed Description

Version of M5UnitUnified, to test at compile time (as ESP_IDF_VERSION)

Keep the values the same as library.properties / library.json / idf_component.yml. M5UnitUnified 0.6.0 and older do not have these macros, so test that they are defined first:

#if defined(M5_UNIT_UNIFIED_VERSION)
#if M5_UNIT_UNIFIED_VERSION >= M5_UNIT_UNIFIED_VERSION_VAL(0, 6, 1)
// Use what 0.6.1 added
#endif
#endif

(The two #if are needed: in one line, an undefined M5_UNIT_UNIFIED_VERSION_VAL() is an error even after a false defined() test.)
